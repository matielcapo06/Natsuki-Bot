# Natsuki Bot 🤖
Template modular para un bot de Discord utilizando **discord.js v14**.

## 🚀 Instalación
1. Clonar el repositorio.
2. Ejecutar `npm install` para instalar las dependencias.
3. Crear un archivo `config.json` en la raíz con el siguiente formato:
```json
{
  "token": "TU_TOKEN_AQUÍ",
  "clientId": "TU_CLIENT_ID_AQUÍ"
}
